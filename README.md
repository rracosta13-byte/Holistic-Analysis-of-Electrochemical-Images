# Holistic-Analysis-of-Electrochemical-Images
MATLAB codes from work
Dataset for this work can be found at https://wrap.warwick.ac.uk/id/eprint/143056/) (Figure 5)
There are 3 different times in this code when running the main script 'electrochemical_image_analysis.m', where a pop-up window will appear for user input.
1) To determine the line numbers for the data. start point is 7 and endpoint is 18 for Figure 5 dataset
2) To remove rows from image. To have the same dimensions as Figure 5, remove top row and bottom 4 rows.
3) segmentation of PC colormap into clusters. an input of 5 provides the separation necessary to segment each grain.
